# iComp Soluciones — Landing

Sitio web para **iComp Soluciones**, agencia de desarrollo de software con presencia en **Caracas, Venezuela** y **Bucaramanga, Colombia**.

## Contenido

La landing incluye:

- Propuesta de valor y servicios FullStack (web, móvil, APIs, cloud, fintech, IA)
- Ámbitos clave, beneficios y portafolio de experiencia por sector
- Canales de contacto (WhatsApp, correo y redes sociales)

## Tecnologías

- HTML5
- [Tailwind CSS](https://tailwindcss.com) (CDN)
- Fuente [Inter](https://fonts.google.com/specimen/Inter) (Google Fonts)

No requiere build ni dependencias de Node.js: basta abrir `index.html` en el navegador o publicar el repositorio en GitHub Pages.
